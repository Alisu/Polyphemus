A process of its own, bin/polyphemus-stop, that holds another one stopped for this image: started through popen and never written to, it lets the process go when the pipe closes -- this image done, or dead -- or at its bound, saying so first. One stop at a time per process, and a stop whose helper was killed is ended by the next (#137, #96, #117; docs/model/StopHelper.tla). Built with cc on first use, beside its source.
