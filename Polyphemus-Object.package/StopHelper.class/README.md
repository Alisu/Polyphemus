A process of its own, bin/polyphemus-stop, that holds another one stopped for this image: started through popen and never written to, it lets the process go when told to (a signal), when this image dies (the pipe closes, or it is no longer the parent), or at its bound, saying so first. The signal and the parent are for macOS, where popen cannot keep the pipe from a child started meanwhile, and that child would keep it open. One stop at a time per process, and a stop whose helper was killed is ended by the next (#137, #96, #117; docs/model/StopHelper.tla). Built with cc on first use, beside its source.
