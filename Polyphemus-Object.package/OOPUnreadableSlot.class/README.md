A slot of an object that does not read: its word points nowhere a reading can follow, or at something that is not an object.

Not a nil: shown as nil, an inspector and a debugger would state a value the image does not hold. It keeps its place among its object's slots, its index, and the reason the reading gave, and says them (#118), as `OOPUnreadableClass` does for a class index that answers nothing.
