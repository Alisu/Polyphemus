Putting our watcher into a running image that has none (#27): a method compiled here, a context to start it and a process at priority 70 holding that context, made in the image and queued on the VM's interrupt semaphore as if already waiting there. From then on an interrupt wakes it, and the image is held, stepped and let go like one launched with the watcher. Chosen over patching a method some process of the image runs: that method would be one the JIT had compiled, and changing its bytecodes would not change what runs. Written in one stop at whatever moment the process was stopped: an image with no watcher has no safe moment to offer.
