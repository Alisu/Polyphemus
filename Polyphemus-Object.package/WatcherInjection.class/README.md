Putting our watcher into a running image that has none (#27): a semaphore registered in a free slot of the image's external objects table, a method compiled here, a context to start it and a process at priority 70 holding that context, made in the image and queued on that semaphore as if already waiting there. From then on a signal of that semaphore from outside -- as the VM's own threads signal one -- wakes it, and the image is held, stepped and let go like one launched with the watcher. Chosen over patching a method some process of the image runs: that method would be one the JIT had compiled, and changing its bytecodes would not change what runs. Written in one stop at whatever moment the process was stopped: an image with no watcher has no safe moment to offer.
