A process of a held image, stepped by that image's own debugger through a channel (#34): Pharo steps by interpreting bytecodes in Smalltalk, so the image needs nothing from us but the request, made by name to its agent's helpers. Both sides name the process by its identity hash, which a move in memory does not change. What is read of the image back -- copies, readings, where the process is -- is its HeldReading's (#118).
