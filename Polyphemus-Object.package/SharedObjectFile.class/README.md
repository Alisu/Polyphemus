A VM library read from its file for its symbols: the bytes, a string at an offset from zero, a little endian number, and a symbol's address by name, which `MachOSharedObject` and `PeSharedObject` each held a copy of (#118). Abstract: a subclass answers `symbols` and `buildId` from its format. `ElfSharedObject` is older, counts its indexes from one and checks its bytes as it reads them; it stays apart.
