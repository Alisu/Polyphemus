What each package of an image owns, in bytes (#69): its classes and metaclasses, their method dictionaries, and their methods with their blocks and method state, each object counted once. What its class variables keep alive is not counted: that needs what keeps what alive. Extension methods count for the class's package. A class's package is read from the image: Pharo 12 and later through the class's PackageTag; Pharo 10 and 11 as the longest RPackage name its category starts with.
