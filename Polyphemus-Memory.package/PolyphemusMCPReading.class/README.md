What a handle of the MCP server stands for: an image file, a core, a process read, or an image held, with what each is asked -- its objects, its processes numbered for the handle's life, a census and a footprint for an image file, a debug session for a held image. Opened through `Polyphemus`, so an image file climbs the ladder `readImageFile:` climbs. A tool asked of a handle of another kind is refused in words (`ToolCallFailed`), saying what the handle is (#118).
