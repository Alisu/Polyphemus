Polyphemus as an MCP server (#71): one JSON-RPC message per line, over standard input and output, so an agent can start it through ssh. It runs in the observer image only: the images it reads are never instrumented. This slice reads image files: open_image, census, packages, all read-only. A tool's own failure is in its result (isError), for the agent to read; only the protocol's errors are JSON-RPC errors.
