The memory of a process on macOS, read through its task port (Mach: task_for_pid, mach_vm_region_recurse, mach_vm_read_overwrite), answering the memory protocol LinuxProcessMemory and ElfCoreDump answer, so SpurDumpedMemory takes it the same way. Its own task needs no privilege; another process's needs the observer run as root, and the target not hardened, as the downloaded Pharo VM is not (docs/handover-macos.md).
